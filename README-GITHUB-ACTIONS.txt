1. Dépose tout le contenu de ce ZIP à la racine de ton dépôt GitHub.
2. Va dans l'onglet Actions.
3. Lance le workflow "Build portable app".
4. À la fin, télécharge l'artifact "planning-maison-sport-sante-portable".
5. Dedans tu auras le fichier "Planning Maison Sport Santé.exe" portable.

Notes :
- Le planning-maison-sport-sante.json est chargé automatiquement au premier lancement.
- Ensuite les modifications sont sauvegardées localement dans l'application via le stockage du WebView.
