- `print-bg.png` : fond graphique

## Mise en ligne rapide avec GitHub Pages
1. Crée un dépôt GitHub.
2. Envoie tous les fichiers de ce dossier à la racine du dépôt.
3. Dans GitHub : `Settings` > `Pages`.
4. Dans `Build and deployment`, choisis `Deploy from a branch`.
5. Sélectionne la branche `main` et le dossier `/root`.
6. Attends la génération du site.
7. Ouvre l'URL GitHub Pages fournie.

## Important
- Le site charge automatiquement le fichier JSON local `planning-maison-sport-sante-cycle-avril-juillet-2026.json`.
- Les liens et chemins sont déjà relatifs, donc adaptés à GitHub Pages.
